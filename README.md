# Cronovisor Aperturas PF

Tablero de solo consulta del avance de aperturas de clubes Planet Fitness México: panorama de clubes en paralelo, matriz de captura por área, cronograma por club y tareas en ejecución de la semana.

Es un solo archivo HTML autocontenido (`index.html`); ábrelo en cualquier navegador. Los datos están en el bloque `DATOS` del script y se regeneran a partir de los archivos TimeLine de cada área.
